# Generate new alien species parameters

Uses a range of traits to produce parameters for an invading species.

## Usage

``` r
alien_synthesis(trait_range = NULL, n = 1)
```

## Arguments

- trait_range:

  A data frame containing parameter ranges, or `NULL` for defaults.

- n:

  Number of alien species to generate. Default is 1.

## Value

A data frame of species parameters.
