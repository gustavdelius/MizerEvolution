# Package index

## Setting up evolutionary models

Functions for creating and customizing evolutionary parameters.

- [`evoParams()`](https://sizespectrum.org/mizerEvolution/reference/evoParams.md)
  : Set up parameters for an evolutionary model
- [`extinctionRDD()`](https://sizespectrum.org/mizerEvolution/reference/extinctionRDD.md)
  : Stock recruitment relationship enabling extinction of species
- [`alien_synthesis()`](https://sizespectrum.org/mizerEvolution/reference/alien_synthesis.md)
  : Generate new alien species parameters
- [`nameGenerator()`](https://sizespectrum.org/mizerEvolution/reference/nameGenerator.md)
  : Generate random species names
- [`tempFun()`](https://sizespectrum.org/mizerEvolution/reference/tempFun.md)
  : Calculate temperature scalar

## Running simulations

Projecting the model forward in time with mutation and species invasion.

- [`evoProject()`](https://sizespectrum.org/mizerEvolution/reference/evoProject.md)
  : Project evolutionary simulation forward in time

## Visualising results

Plotting evolutionary dynamics, traits, spectra, and vital rates.

- [`plotDynamics()`](https://sizespectrum.org/mizerEvolution/reference/plotDynamics.md)
  : Plot biomass variations through time of species and phenotypes
- [`plotSS()`](https://sizespectrum.org/mizerEvolution/reference/plotSS.md)
  : Plot size spectrums of species and phenotypes
- [`plotevoFeeding()`](https://sizespectrum.org/mizerEvolution/reference/plotevoFeeding.md)
  : Plot feeding level
- [`plotevoGrowth()`](https://sizespectrum.org/mizerEvolution/reference/plotevoGrowth.md)
  : Plot growth
- [`plotStarvation()`](https://sizespectrum.org/mizerEvolution/reference/plotStarvation.md)
  : Plot starvation level
- [`plotevoMortality()`](https://sizespectrum.org/mizerEvolution/reference/plotevoMortality.md)
  : Plot total mortality
- [`plotSpawn()`](https://sizespectrum.org/mizerEvolution/reference/plotSpawn.md)
  : Plot spawn
- [`plotPredRate()`](https://sizespectrum.org/mizerEvolution/reference/plotPredRate.md)
  : Plot predation rate
- [`plotPredMort()`](https://sizespectrum.org/mizerEvolution/reference/plotPredMort.md)
  : Plot predation mortality rate of each species against size
- [`plotevoTrait()`](https://sizespectrum.org/mizerEvolution/reference/plotevoTrait.md)
  : Plot trait evolution through time
